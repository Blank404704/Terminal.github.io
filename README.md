# Terminal
## Description
This is Terminal. You are NoUser trying to do something strange... BUT you are being hunted, need to play games, and are interacting with a terminal to do so, so multitasking is a trait you will need.
## How to play
To play:
* Enter commands in the terminal and explore the files.
* Keep the red dot away from the green dot on the map.
* And play the `.exe` files.
Easy :}
